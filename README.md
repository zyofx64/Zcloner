## Zcloner

Clonador de sites básico feito em Python.

O ZCloner é uma ferramenta simples para clonar páginas web para uso local, utilizando Python e Chromium.

> observação: tem alguns detalhes nele ainda não está completo.



Requisitos

No Termux, instale o Chromium:
```
pkg install chromium
```
Verifique se o Chromium está disponível:
```
which chromium-browser
```
Instale as dependências Python:
```
pip install -U requests beautifulsoup4 urllib3
```
Instalação

Clone o repositório:
```
git clone https://github.com/zyofx64/Zcloner.git
```
Entre na pasta:
```
cd Zcloner
```
Como usar

Execute:
```
python zcloner.py
```
O programa iniciará, onde você poderá selecionar o alvo e configurar as opções da clonagem.
